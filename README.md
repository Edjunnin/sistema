# Sistema

Projeto em CodeIgniter 4 para gestão de conteúdo e páginas institucionais.

## Objetivo

Centralizar a apresentação de páginas como Home, Contato, Histórias, Habilidades e Planos Futuros.

## Tecnologias

- PHP
- CodeIgniter 4
- HTML/CSS
- MySQL

## Execução

1. Ajuste as configurações do banco em `app/Config/Database.php` e `.env`.
2. Configure a URL base do projeto.
3. Inicie o servidor local do CodeIgniter.

## Estrutura principal

- `app/Controllers` - controladores
- `app/Views` - páginas e layouts
- `app/Models` - regras de acesso aos dados
- `public/assets` - arquivos estáticos
- `database` - scripts do banco
